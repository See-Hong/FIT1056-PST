# Music School Management System (MSMS) (The Persistence Upgrade)
A text based application that helps with the management of a music school. <br>
The application can be used for student and teacher data management.

## Features
- Register new students and teachers.
- Enrol and unenrol students in school courses.
- Update student and teacher information.
- Remove student and teacher from system.
- Student check in system for attendance.
- Check student attendance for certain dates.
- Prints student card file.
- Lists students and teachers in the school system.
- Search for students and teachers using search terms.
- Admin login system, letting certain functions be admin-only.
- Persistent data management. System data is stored in json files.

## Installation
1. Clone the repository
``` bash
  git clone https://github.com/See-Hong/FIT1056-PST.git
  cd FIT1056-PST
  pip install -r requirements.txt
```
2. Run the program
```
cd PST2
python pst2_main.py
```
