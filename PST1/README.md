# Music School Management System

This is a text based application that helps with the management of a music school

## Features

- Register new students and teachers.
- Enrol and unerol students in courses.
- Lists students and teachers in the school database.
- Search for students and teachers using search terms.

## Installation

1. Clone the repository
```bash
git clone https://github.com/See-Hong/FIT1056-PST1.git
cd FIT1056-PST1
pip install -r requirements.txt
```
2. Run the program
```bash
python MSMS.py
```
